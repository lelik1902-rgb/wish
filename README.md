# wish

Проста оболонка Unix мовою C++17, виконана за завданням
[OSTEP processes-shell](https://github.com/remzi-arpacidusseau/ostep-projects/blob/master/processes-shell/README.md).
Каталог `tests/` і `tester/run-tests.sh` узято без змін із репозиторію завдання (коміт `76cff3f`).

## Збирання і запуск

Потрібні Linux (або WSL), g++ і make.

```sh
make            # збирає ./wish
./wish          # інтерактивний режим, запрошення "wish> "
./wish file     # пакетний режим, без запрошення
make test       # офіційні тести
```

Тест 3 перед запуском перезаписує `tests/3.out` і `tests/3.err` виводом системного `ls`, тому
ці файли можуть відрізнятися від закоміченої версії. Повернути їх можна так: `git checkout tests/3.err tests/3.out`.

## Можливості

- Вбудовані команди: `exit`, `cd <каталог>`, `path [каталог ...]`. Початковий шлях: `/bin`.
- Зовнішні програми: `fork`, `execv`, `waitpid`; пошук виконуваного файла через `access`.
- Перенаправлення `cmd > file`: stdout і stderr ідуть у файл, файл обрізається.
- Паралельні команди `a & b & c`: запускаються всі, потім оболонка чекає на кожну.
- Єдине повідомлення про помилку: `An error has occurred`.

## Рішення там, де специфікація не визначає поведінку

- Синтаксична помилка в будь-якій частині рядка скасовує весь рядок: не запускається нічого.
- Вбудовані команди в рядку з `&` виконуються у самій оболонці, зліва направо.
- `exit` у рядку з `&` спершу дочікується вже запущених процесів.
- Абсолютні й відносні шляхи до програм окремо не підтримуються (завдання цього не вимагає),
  тому з порожнім `path` не запускається жодна програма.
- Перенаправлення для вбудованих команд ігнорується (завдання цього не перевіряє).
